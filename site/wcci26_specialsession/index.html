About the session

Official IJCNN / WCCI 2026 event page ↗

Large-scale audio, video, imaging, and environmental sensor data can help fill gaps in biodiversity monitoring. This session explored machine learning and signal processing methods that turn those data streams into ecological evidence, while accounting for the complexity of real habitats.

Topics

  • Machine learning for large-scale bioacoustic data and automated species detection
  • Population size estimation from acoustic or multimodal data
  • Representations and deep learning for ecological monitoring
  • Integration of audio, visual, and sensor modalities
  • Case studies, tools, datasets, and reproducibility
